# 🔎 GitHub Profile Finder

Application frontend développée en JavaScript permettant de rechercher des profils GitHub, afficher leurs informations et gérer une liste de favoris.

---
## 🚀 Fonctionnalités

### 🔍 Recherche
- Recherche d’un utilisateur GitHub par pseudo
- Affichage du profil :
  - Avatar
  - Nom / Username
  - Bio
  - Followers / Following
  - Nombre de repositories
  - Lien vers GitHub

  ### 📦 Repositories
- Affichage des 5 repos les plus populaires
- Informations :
  - Nom
  - Description
  - Langage
  - Nombre de stars ⭐
  
  ### ⭐ Favoris
- Ajouter un profil aux favoris
- Supprimer un profil des favoris
- Afficher la liste des favoris
- Cliquer sur un favori pour recharger son profil
- Compteur dynamique des favoris
- Sauvegarde persistante avec localStorage
